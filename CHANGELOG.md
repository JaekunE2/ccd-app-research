## 1.0.0
- Packaged as an Agent CLI Hub store app: the harness installs into a folder you choose, its limits come from the
  install settings, and a small hub plugin tells the hub's research view where it is.
- Research gates (GATES.md): question first, independent ground truth, baselines first, pilot before writing,
  closing a project as killed / archived / completed with FINAL.md.
- P10 (submission prep) is a user choice and waives the review gate; the external reviewer and the venue benchmark
  refuse truncated input.
- The hub CLI is found through `CCD_JS`, `config.json "ccd"` or a hub next to the harness.
